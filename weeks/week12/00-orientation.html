Week 12 — Talking to Memory and the World

The memory bus, memory timing, input and output, and the system call  |  11/02 – 11/08  |  Estimated time: ~6.5 hours

Your CPU can’t talk to anything yet.

Last week your control unit ran an instruction by itself: twenty-four clicks, and a register held a new value. But every part it used was a register on the bus. Your RAM sits in its own tab, waiting for Week 13. There is no keyboard and no screen. And the MARS programs you have written since Week 5 ended with syscall, an instruction that asks for something no program can do for itself.

This week is about everything on the other side of the processor: how a CPU asks memory for a byte, what happens when memory is slower than the CPU, how a program reaches a keyboard or a display, and what syscall actually does. It closes Phase 3, so it ends with Quiz 2 on Weeks 9 to 12.
