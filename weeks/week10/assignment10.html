Tab CPU — the bus and the core

  1. The bus: eight 1-bit wire loops, innermost = bit 0, outermost = bit 7 (page 1, §10.4). Leave a large empty space in the middle; the control unit goes there in Week 11.
  2. On the bus, through splitter fans: R0, R1, R2 and R3 (both i and o); ACC’s o; TMP’s i; the ALU’s A; and a test port — an 8-bit input pin data through an 8-bit controlled buffer controlled by an input pin data_e. The test port is scaffolding for loading values by hand; nothing later depends on it.
  3. Off the bus: TMP o → BUS1 i; BUS1 o → ALU B; ALU C → ACC i; ALU CO, AL, EQ, Z → FLAGS c_in, a_in, e_in, z_in.
  4. REG_SELECT’s eight outputs to R0–R3’s e and s.
  5. Control input pins, all pull-down: ra, rb (2 bits) to REG_SELECT; rega_e, regb_e, regb_s to REG_SELECT; tmp_s to TMP; acc_e, acc_s to ACC; flags_s to FLAGS; bus1 to BUS1; opcode (3 bits) and ci to the ALU; data and data_e for the test port.
  6. Probes on the reg output of R0–R3 and ACC, on TMP’s o, the ALU’s C, the four FLAGS outputs, and the bus (combine the eight loops through one more splitter into an 8-bit probe).

Submission checklist

  • All circuits are contained within this single .circ file — no external file links
  • TMP, BUS1, FLAGS, REG_SELECT and CPU present, pins named exactly as above
  • REGISTER_8BIT, MEM_8BIT, MEM_1BIT, DECODER_2TO4 and ALU_8BIT instantiated from the tabs you already had — none rebuilt, none modified
  • Every splitter fan connects bit 0 to the innermost bus loop
  • Only TMP’s i, the ALU’s A, ACC’s o, R0–R3, the test port and the bus probe touch the bus
  • Ten screenshots, one per verification step
  • Only Wiring and Gates components used — nothing from Plexers, Arithmetic or Memory
