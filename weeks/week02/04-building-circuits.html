Opening Logisim and Creating Your Course File

If you did this during orientation, skip ahead. If not, do it now.

  1. Launch Logisim Classic 2.7.1. Not Logisim Evolution.
  2. Choose File › New.
  3. Save immediately as CSC210_YourName.circ. This is the only Logisim file you will create for this course.
  4. To add a circuit tab: Project › Add Circuit. Name each one exactly as the assignment specifies — NAND_NOT, NAND_AND, and so on. The grader looks for those names.

The Primitive Gate Library

Open the Gates library in the panel on the left. The gates you will use are the seven you already know: NAND, AND, OR, NOT, NOR, XOR, XNOR.

Primitive gates only

Do not use the built-in Adder, Multiplexer, Decoder, Register, RAM, or any other composite component from the other library panels. Every circuit in this course is built from primitive gates.

The only exceptions are Input pins, Output pins, and (later in the course) the Clock source. Using a built-in Adder in Week 3 would mean skipping the part where you learn what an adder is.

Building Your First Circuit: NOT from NAND

  1. Select the NAND gate from the Gates library and place it on the canvas.
  2. Select the Input pin and place one. This circuit has a single input — do not place a second pin. An unconnected input pin floats, and Logisim will flag it as an error.
  3. Select the Output pin and place one.
  4. Using the wiring tool, connect the input pin to both inputs of the NAND gate. Draw a wire to the first input, then draw a second wire from the same pin to the second input.
  5. Connect the NAND's output to the output pin.
  6. Label the input pin A and the output pin NOT A.
  7. Switch to the poke tool (the hand icon) and click the input pin to toggle it between 0 and 1. Watch the output change.

What you are seeing: when you toggle the input from 0 to 1, voltage propagates through the NAND gate and the output flips from 1 to 0. You have built a NOT gate — a decision-making circuit — from a single NAND. That is the physical mechanism behind every computation your computer performs.

Watch for the three-state warning

If a wire shows blue instead of green or dark green, it is carrying an undefined value — usually because something is unconnected. Blue means "nothing is driving this wire," not "zero." Trace it back and connect it.

This is the single most common thing that goes wrong on a first Logisim circuit, and it is why step 2 above says one input pin rather than two.

2.6 — From Expression to Circuit: A Design Exercise

You can build individual gates from NAND. Now take a complete Boolean expression and design a circuit that computes it. This is a process, not an act of inspiration — follow the same five steps every time and it will work every time.

Step 1
Read
Identify the operations and the order they apply in. Watch the primes carefully.
Step 2
Tabulate
Write the truth table for every input combination. This is your target — and later, your test.
Step 3
Decompose
Break the expression into sub-expressions, each of which maps to exactly one gate.
Step 4
Build
Place the gates and wire them according to the decomposition.
Step 5
Verify
Poke every input combination. Confirm each one against step 2. Every one, not a sample.

Worked Example

Take the expression:

F = (A AND B) OR (NOT C)

Decomposed:

  • A AND B → one AND gate
  • NOT C → one NOT gate
  • OR the two results together → one OR gate

Three gates total. Now the truth table — note that with three inputs there are eight rows, not four:

ABCA AND BNOT CF
000011
001000
010011
011000
100011
101000
110111
111101

You will build exactly this circuit in Assignment 2. Notice that F is 1 in six of the eight rows — if your circuit produces something with a different shape, the truth table tells you which row to investigate first.

Forward reference

In Week 3 you apply this same five-step process to build a half adder — a circuit that adds two bits. The sum output is A XOR B and the carry output is A AND B. The process is identical: expression, truth table, decomposition, build, verify. Only the expression changes.

2.7 — Synthesis: The Single Molecule of Computation

Let's connect the dots.

You started this week with a question: how does voltage become a decision? You learned that a transistor is a voltage-controlled switch. You learned that transistors wire together into logic gates. You learned that the NAND gate is universal — any logic function at all can be built from NAND gates alone. And you proved why, using De Morgan's laws.

Here is what that means. Every circuit you will build in this course — the adder in Week 3, the S-R latch in Week 4, the register in Week 5, the ALU in Week 6, the RAM in Week 8, and the CPU you assemble across Weeks 13 and 14 and submit as your final project — can be built from nothing but NAND gates.

The CPU in your laptop was not built from NAND gates alone; modern chips use a mix of gate types for efficiency. But it could have been, and nothing about what it can compute would change. The NAND gate is the single molecule of computation. Every piece of software you have ever run — every game, every browser tab, every line of code you have written — ultimately executed as voltage flowing through gates like the one you just built.

This is not a metaphor. The Intel 4004, the first commercial microprocessor (1971), was built almost entirely from NAND logic. The Apple I used chips made the same way. You are learning the same physical principle that powered the first computers, and you are about to build with it.

2.8 — Looking Ahead: From Single Gates to Useful Circuits

You now know the alphabet of digital logic. You can build any single gate from NAND gates alone, and you can translate a Boolean expression into a working circuit.

But single gates are like individual letters. They are the vocabulary, and they do not say much on their own.

Where this goes

What we have: individual logic gates that compute simple functions.

What we can't do yet: build circuits that compute anything useful — add numbers, select between values, decode an address. Single gates are not enough.

What you will be able to do next week: build combinational circuits that perform arithmetic and selection on multi-bit values. The adder you build in Week 3 is made of the same gates you learned this week, wired together in a pattern that performs binary addition.
