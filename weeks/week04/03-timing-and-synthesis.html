4.6   Reading a Timing Diagram

Everything so far has been described in words: this one follows, that one samples, this one holds. Words are a poor tool for it. The difference between three storage devices is a difference in when, and when is a picture.

How to read one

A timing diagram is simple once you have seen one:

  • Time runs left to right. Each column is one moment.
  • Each row is one signal. High means 1, low means 0.
  • A vertical line is a change. Flat means nothing happened.

That is the whole notation. What makes it powerful is putting several signals on the same time axis, so you can see what each one was doing at the moment another one changed.

Three devices, one input

Below, all three devices get the same data and the same control signal. Nothing else differs between them.

  • The raw S-R latch from page 1, driven so that a 1 sets it and a 0 resets it. It has no enable at all — nothing can tell it not yet.
  • Your MEM_1BIT from page 2, with the control signal on its Set input.
  • A D flip-flop, the edge-triggered device from section 4.5, with the same signal used as its clock.

Click any cell in the top row to change the input and watch all three outputs recompute. Drag the scrubber to walk through time one moment at a time and read what is happening.

What the picture says

Following versus sampling

The S-R latch row is identical to the input row. Always, in every preset. It has no control input, so it has no way to not respond — it simply is whatever it was last told.

Your MEM_1BIT copies the input in bands. While the control signal is high, its row and the input row move together. The moment the control drops, its row goes flat and stays flat — holding whatever the input happened to be at that instant.

The flip-flop row changes only at the marked edges, and is flat everywhere else. Between two edges you can do anything you like to the input and the flip-flop's row does not move.

The second preset is the one worth sitting with. The input goes high, stays high for four moments, and comes back down — all between two clock edges. The flip-flop's output never moves at all. Not delayed, not smoothed. The pulse is invisible to it, because it happened at a time the flip-flop was not looking.

That is what "sampling" means, and it is the property that makes synchronous design work: a device that only looks at known moments cannot be confused by what happens between them.

The skill you should leave with

Given an input and a control signal, draw the output

Being able to do this by hand — for a level-sensitive cell and for an edge-triggered one, and get the difference right — is assessed in three places:

  • Lab 4, where you draw waveforms and then check them against Logisim.
  • Assignment 4, Part B, where you draw both and explain where they differ.
  • Quiz 1, where you are asked about the difference in words.

It is also the skill you will use every time a circuit misbehaves in Weeks 11 through 14. Practise it here, where the answer is on screen.

4.7   Synthesis: You Have Built Memory

Two tabs in your .circ file that were not there on Monday.

  • SR_LATCH — two cross-coupled NAND gates. The mechanism in its rawest form, and the one circuit this semester you built in order to understand rather than to use.
  • MEM_1BIT — four NAND gates, three pins. Your CPU's memory cell.

And one idea, which is worth stating once and not padding:

Memory is feedback

There is no memory ingredient. There is a loop — a circuit whose output is part of its own input, settled into one of two stable states, held there by nothing but its own consistency.

Everything above it in the machine is that idea with more wires. A register is eight of them. RAM is thousands. The program counter is one that can also count. There is no second mechanism anywhere in a computer for remembering things.

What happens next

Week 5

Eight of these memory cells, wired in parallel with a shared Set line, become a register.

That is the entire step. Eight copies of the block you just drew, one control line running to all of them, so that a whole byte is captured at once instead of a bit.

Week 5 adds one more thing around the outside: a way to get the byte back out onto a shared wire without every register shouting at once. Storing and speaking are two different controls, and you have built the first one.

Phase 2 also opens a second track. Alongside the register, you start writing MIPS assembly in MARS — and the first register you will type the name of, $t0, is eight of the circuits sitting in your file right now. The two halves of this course meet there and stay together for the rest of the semester.
