Assignment 5: The Register and the Instruction

100 points   Assesses: SLO1, SLO2 and SLO3  |  Estimated time: ~2.5 hours

Four parts, covering both halves of the week. Part A is Logisim Checkpoint 1. Parts C and D are your first graded MIPS work.

Same file, three new tabs

Open the same CSC210_YourName.circ you have been building since Week 2. This week's circuits are new tabs in that file, and MEM_8BIT is built from instances of your own MEM_1BIT from Week 4 — not from re-drawn gates.

Every circuit must be inside this one .circ file. In your instructor's words, from the final-project requirements: "You MUST include ALL of the circuits necessary for the CPU simulation in your final submission file. Do not link any libraries in your project other than those included by default."

This is the first week where a "master file that links to the others" would look like a reasonable way to organise things. It is not, and a submission built that way opens as a broken circuit on the grading machine.

Which components you may use — including one that surprises people

Anything from Logisim's Wiring folder (pins, splitters, tunnels, constants, probes) and anything from Gates.

The controlled buffer is in the Gates folder, and it is permitted. You need nine of them this week. After three weeks of "build it from gates" it is natural to hesitate over anything that looks like a finished component — do not. It is a primitive, like a NAND gate, and page 1 explains why it cannot be built from the others.

Nothing from Plexers, Arithmetic, or Memory. The Memory folder contains a Register that would do Part A for you. Using it scores zero for that circuit, however well it works.

xxxxxxxx is a correct result, not a fault

When e = 0, your enable circuit and your register should show xxxxxxxx on the output pin — not 00000000.

That means the controlled buffers are doing their job: the register has stopped driving the wire entirely. Every year, students see the xs, assume something is broken, and delete the buffers. Do not.

Start Part A early

Part A is the largest single piece of this assignment and it is a build, which means it can fail in ways reading about it will not predict.

Plan accordingly: start early enough that you can ask about it before the week ends.

Do not leave out reg

It is easy to miss, because nothing downstream in the CPU consumes it. It is graded, and it is what lets you see inside a register in Weeks 13 and 14 without putting it on the bus — which would change the thing you are trying to observe.

Also: label s and e on the circuit appearance. They are two identical-looking 1-bit pins side by side on the same edge, you will place this block a dozen times, and getting them the wrong way round produces a register that writes when it should read, with no error message anywhere.

Part A — Logisim Checkpoint 1: The 8-Bit Register (50 points)

Assesses SLO1. Build all three circuits as separate tabs.

Circuit 1 — MEM_8BIT (14 points)

  1. Place an 8-bit input pin named i. Run it into a splitter to get eight 1-bit wires.
  2. Place eight instances of your own MEM_1BIT from Week 4. Wire one bit of i into each cell's In.
  3. Place one 1-bit input pin named s and branch it to all eight Set inputs.
  4. Recombine the eight Q outputs through a splitter into an 8-bit output pin named o.
  5. Edit the circuit appearance to a labelled rectangle, taller than wide: i left, o right, s bottom.
Verify
  • s = 1, i = 10101010 → o = 10101010.
  • Drop s to 0, then change i to something else → o does not move. This is the test that matters.

Circuit 2 — ENABLE_8BIT (14 points)

  1. 8-bit input pin i, through a splitter into eight wires.
  2. Eight AND gates. One input of each is a bit of i; the other input of all eight is a 1-bit pin named e.
  3. Put a controlled buffer on each AND gate's output — eight of them — with every buffer's control input also driven by e.
  4. Recombine through a splitter into an 8-bit output pin o.
  5. Edit the appearance to a labelled rectangle: i left, o right, e bottom.
Verify
  • e = 1 → o equals i.
  • e = 0 → o reads xxxxxxxx. If it reads 00000000, your buffers are missing or their control input is not wired to e.

Circuit 3 — REGISTER_8BIT (18 points)

  1. Place one MEM_8BIT and one ENABLE_8BIT.
  2. 8-bit input pin i → MEM_8BIT's i. A 1-bit pin s → its s.
  3. MEM_8BIT's o goes two places: into ENABLE_8BIT's i, and to an 8-bit output pin named reg.
  4. A 1-bit pin e → ENABLE_8BIT's e.
  5. ENABLE_8BIT's o → through one more controlled buffer, 8 bits wide, also controlled by e → the 8-bit output pin o.
  6. Edit the appearance to a labelled rectangle with all five pins, s and e clearly distinguished.
Yes, that is nine buffers, and the ninth looks redundant

It is, on paper — the eight inside ENABLE_8BIT have already floated every bit. Build it anyway. Without it, the simulation in Logisim Classic 2.7.1 becomes unstable: not wrong answers, unreliable ones. Page 1, section 5.3b, explains what that is about and why it is worth knowing.

Verify — all five steps, in order
  1. s = 0, e = 0 → o reads xxxxxxxx.
  2. Set i = 11001100, raise s to 1 → reg shows 11001100. o is still xxxxxxxx.
  3. Drop s to 0, change i to 00000000 → reg stays 11001100.
  4. Raise e to 1 → o becomes 11001100.
  5. Drop e to 0 → o returns to xxxxxxxx; reg unchanged throughout.

Step 2 is where reg earns its place: without it you could not confirm the write happened without also asserting e.

Part B — Written: Storing and Speaking (15 points)

Assesses SLO1. Two or three sentences each. Answer in your own words.

1. (5 points) MEM_8BIT is eight MEM_1BIT cells. Explain what the single shared s line does that eight separate Set lines would not — and why that difference is what makes the circuit store a byte rather than eight bits.

2. (5 points) A register whose "silent" state is to drive 00000000 cannot share a bus. Explain why, in terms of what is physically on the wire — not in terms of a rule that the control unit has to follow.

3. (5 points) Your REGISTER_8BIT has two outputs. Describe the difference between o and reg, and give one specific situation in which you would need reg and o would not do.

Part C — Instruction Encoding and Decoding (28 points)

Assesses SLO2. Seven problems, 4 points each. Full marks require every field correct. The reference tables are at the bottom of this page — you do not need to leave it.

Encoding — assembly to machine code

Give the binary contents of every field, then the assembled 32 bits.

1. (4 points) sub $s0, $t8, $t9

2. (4 points) lw $t1, 64($sp)

3. (4 points) addi $v0, $a1, -50

The immediate is negative. Sixteen bits, two’s complement — Week 1, in a new place.

4. (4 points) j 8192

Decoding — machine code to assembly

Identify the format first, then split the fields, then write the instruction.

5. (4 points)

6. (4 points)

7. (4 points)

Count the digits before you start on problem 7

Every instruction is 32 bits, and the quickest way to go wrong on a J-type is to mis-split a 26-bit address. Count first.

  • One s line reaches all eight cells
