Week 1 Orientation

Estimated time: ~15 minutes  |  Prerequisites: None

The Gap Between Voltage and This Webpage

Every program you have ever written exists inside your computer as nothing more than patterns of electrical voltage. A wire either has voltage on it, or it doesn't. Two states. That is the entire physical vocabulary of a digital computer.

Yet the computer you are sitting at right now can display this sentence in color, play video, run a web browser with dozens of tabs, and compile code you write in Python, Java, or C. How is that possible when the underlying hardware only understands ON and OFF?

The Gap

What you know: You can count, add, and represent any number using the ten digits (0–9) you've used since childhood. You know what a "byte" is, at least vaguely, and you've seen "hex" in color codes or memory addresses.

What you can't do yet: Explain how a machine that only understands "voltage present" or "voltage absent"—two states—can represent the number 2,731, the letter 'M', or the color blue.

What you will be able to do by the end of this week: Take any integer, character, or simple data value and show exactly how it is stored as a sequence of 0s and 1s in computer memory. More importantly, you will understand that the same sequence of bits can mean completely different things depending on how the computer interprets them—which is the single most important idea in this entire course.

Interactive: Computer Components Explorer

Click on each component to learn its role. Understanding these components helps you see how they work together to execute programs—this is the hardware behind every abstraction you'll meet this semester.

🧠 CPU (Central Processing Unit)
The "brain" of the computer. Fetches, decodes, and executes instructions one at a time, billions of times per second. Everything you build in Logisim this semester—from a single flip-flop to a full CPU—is a piece of what happens inside this box.
💾 Memory (RAM)
Fast, temporary, addressable storage. Holds both the program's instructions and its data while the CPU works. You'll build a scaled-down RAM matrix by hand in Week 8.
🗄️ Storage (Disk/SSD)
Slower, persistent storage that keeps data even when the power is off. Sits below memory in the memory hierarchy you'll study in Week 16.
🔌 Input / Output
Keyboards, displays, network cards—anything that moves data in or out of the system. You'll see how the CPU talks to I/O devices via software interrupts in Week 12.
Where This Is Going

Right now these are just labeled boxes. By Week 17, you will have built a working simulation of the CPU box above—from individual logic gates, all the way up.

Interactive: Abstraction Layers

Computers work through layers of abstraction—each layer hides the complexity of the layer below it. Click each layer to see how they build on one another, from the application on your screen down to the physics that makes it possible.

🖥️ Applications & User Programs▼
The software you use daily—web browsers, games, word processors. Written in high-level languages, focused on user functionality rather than hardware details.
📝 High-Level Languages (Java, Python, C++)▼
Languages closer to human language, providing abstractions like variables, functions, and objects that make programming easier but must be translated to lower levels.
⚙️ Assembly Language & Machine Code▼
Low-level languages that directly correspond to processor instructions. Assembly uses mnemonics like "ADD" and "MOV"; machine code is pure binary. This is what you'll study extensively starting Week 5.
🔧 Microarchitecture & Hardware▼
The physical implementation of the processor—how instructions are actually executed using registers, ALUs, and control units. Built in Logisim starting Week 5.
🚥 Digital Logic & Gates▼
Boolean logic implemented with transistors. AND, OR, NOT gates combine to create adders, multiplexers, and everything else you'll build starting Week 2.
⚛️ Physics & Transistors▼
The fundamental physics of semiconductors—billions of tiny switches made from silicon, turned on or off by electrical signals. Where the digital world meets the physical world, covered in SPA 1 this week.

The Thread That Connects Everything

Every new concept in this course is introduced with three elements:

  1. "Here's what we have so far" — anchored to the concept you just learned
  2. "Here's the problem we can't solve yet" — creating the need for the next concept
  3. "Here's what we can now do" — closing the loop and showing forward progress

No module will feel disconnected. Every step is a necessary rung on a single ladder from raw voltage to a working computer.
