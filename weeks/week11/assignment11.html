Tab ALU_8BIT — one attribute

Select the A input pin and set its pull behaviour to pull-down. Nothing else in the ALU changes. CLF depends on it: with nothing driving the bus, the ALU must see 00000000 at A (page 3, §11.11).

Tab CPU — what changes

  • Delete the input pins ra, rb, rega_e, regb_e, regb_s, tmp_s, acc_e, acc_s, flags_s, bus1 and opcode. The control unit drives all of those wires now.
  • Place one CLOCK and one CONTROL_UNIT in the space you left in Week 10. Connect CLOCK’s clk, clk_e and clk_s to the control unit, and each control-unit output to the wire its old input pin drove.
  • Add input pins clk_in (1, to CLOCK), ir (8, to CONTROL_UNIT) and data_s (1, pull-down).
  • The test port: REG_SELECT’s regb_s input becomes an OR of the control unit’s regb_s and data_s. Keep data, data_e and ci as they were; ci stays at 0 this week.
  • Probes on clk, clk_e, clk_s and steps, as well as everything you probed in Week 10.
Loading a register, and choosing an instruction

To put a value in a register by hand: set ir so that its last two bits name the register (10000000 for R0, 10000001 for R1, and so on), set data, raise data_e, pulse data_s, drop data_e. REG_SELECT sends data_s to the register named by rb.

Load registers and change ir only while steps shows step 1, 2 or 3 — right after Simulate → Reset, or after the 24th click of an instruction. In steps 4 to 6 the control unit is using the bus and acting on ir.
