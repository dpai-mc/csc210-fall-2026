What To Do This Week

There is no graded problem set this week. Week 1 is about getting your environment set up and starting the reading—so use the time to do those carefully rather than quickly.

  • Watch the welcome video above. It covers the syllabus, course policies, and how the semester is structured.
  • Download and install Logisim Classic 2.7.1 and MARS. Links are posted in this week's module. Windows builds are executables; Mac requires a few extra steps, which the lab session covers. If a download will not open, let me know.
  • Create a Saylor Academy account and self-enroll in CS301: Computer Architecture. Create the account at saylor.org, then find the course under Courses and Programs → Computer Science → CS301, and click Enroll. It is free. Until you enroll, you only see the syllabus, not the unit content.
  • Work through this week's learning modules in order. The Week 1 sequence is: Why Binary → Converting Between Bases → Signed Integers and Two's Complement → Beyond Integers (floating point). Do signed integers before floating point—the second builds on the first. Move to them through the Canvas module list, and take your time; do not try to rush them all in one sitting.
  • Optional: try the Cisco Binary Game linked in this week's module. It is a timed decimal↔binary drill and a painless way to get fluent at conversions.

How the Course Is Organized

Everything is delivered through Canvas modules, and the semester runs in four phases:

Phase 1 — Digital Foundations (Weeks 1–4)
Binary and number systems, two's complement, floating point; transistors, gates, and your first circuits; combinational logic—adders, decoders, comparators; and how a single bit gets stored.
Phase 2 — MIPS Assembly Language
Instruction formats, registers, memory access, control flow, and procedures—written and debugged in MARS.
Phase 3 — CPU Design
Datapath and control, the instruction cycle, control signals, and the bus—while you assemble your 8-bit CPU simulator piece by piece from the circuits you already built.
Phase 4 — Integration & Modern Topics
Memory hierarchy, I/O, performance, and current directions in architecture—plus the final 8-bit simulator project.
About the Final Project

The 8-bit CPU simulator is the spine of this course, not a last-minute deliverable. It is submitted in staged checkpoints across the semester, and those checkpoint submissions are not accepted late—the whole point of the staging is to keep you from discovering in December that a semester's worth of circuit-building cannot be done in a week. Every circuit you build from Week 3 onward is a part you will reuse.
