Zoom in: the AI reviewer loop

This is the part people usually mean by "the AI." It isn't one question and one answer. Code builds the question, the model answers in a fixed format, and code checks the answer before anything is kept.

What makes this an "agent" and not a chatbot?

A goal

"Report how this whole course lines up with its official outline." Not one question but a job with many steps.

Tools

Code that can open pages in a browser, read PDFs and quiz files, add up points and write spreadsheets. The model doesn't do these itself.

A model for judgment

The LLM is called hundreds of times, once per page or assignment, only where reading and judgment are needed.

Checks and a loop

Every answer is checked, bad ones go back for another try, and one failed page doesn't stop the run.

Dependencies

Ask for the compliance report and the agent works out what it needs first (read the COR, review the pages) and does only the steps whose inputs changed.

Guardrails and a human

Hard privacy rules in code, and an instructor who reviews every output before it's used.

Code or AI? Who does what

JobDone byWhy
Which pages are live, and in what weekCodeA fact in index.html. Exact every time.
Do the points add up?CodeArithmetic. An AI can get it wrong, and code can't.
Keep student work outCodeA safety rule must never depend on the model "deciding" to follow it.
Does this page teach COR topic 4, and how deeply?AINeeds reading comprehension and judgment; the wording rarely matches the COR exactly.
Does this assignment really assess outcome 2?AIA printed "SLO 2" label is a claim. The model checks what students actually do.
Short answer-key notesAI, then a humanUseful drafts, but they can contain confident technical errors.
Outcome scores (met / partly met / not met)CodeThe instructor's fixed formula: 75%+ = met, later attempts weigh more.

Discussion questions

  1. Look at the color legend. Roughly what share of the diagram is AI, and what share is plain code? Did that surprise you?
  2. The privacy gate is plain code, not an instruction to the AI ("please ignore student work"). Why is that the safer design?
  3. The agent runs on a local model on two graphics cards. What would change if it used a cloud model instead: cost, speed, quality, privacy?
  4. The feedback arrow runs from the instructor back to the course profile. What would happen to this system without it?
