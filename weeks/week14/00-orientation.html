Week 14 — The Finished Machine

Load, store and immediates; jumps; carry-in; END; loading and running a program  |  11/16 – 11/22  |  Estimated time: ~9 hours

Your CPU can’t make a decision yet.

Last week your CPU fetched and ran a program on its own. But it ran straight through, byte 0 to the end, every time. It could not read a value from memory or write one back, could not load a constant, and could not choose between two paths. It also could not stop: after the last instruction it fetched zeros forever.

This week you wire the rest of the instruction set — LD, ST, DATA, the three kinds of jump, carry-in and END — and the harness your instructor’s CPU used to load a program from a file and run it at full speed. At the end of it your CPU can run MYSIM.txt, the 5 × 5 program you decoded in Week 10, and stop with 25 in R2.
