Week 2: Making Decisions from Voltage

Estimated time for this page: ~15 minutes  |  Estimated time for the full week: ~9 hours  |  Topic: Logic Gates

What We Have / What We Can't Do / What We Can Now Do

What you learned last week: Any piece of data — an integer, a character, a color, an instruction — can be represented as a sequence of 0s and 1s. You can convert between binary, hexadecimal, and decimal. You understand that the same bit pattern can mean different things depending on context.

What you can't do yet: Explain how a computer actually does anything with those bits. Representation is passive — the bits just sit there. How does the machine make decisions, perform operations, or transform one pattern into another? There is a gap between "here is a number in binary" and "the computer computed something."

What you will be able to do by the end of this week: Build circuits from individual logic gates that compute any logical function from voltage alone. You will open Logisim for the first time and wire real gates together to see electricity make decisions. You will understand that the NAND gate is universal — an entire computer can be built from nothing but NAND gates — and this is not theoretical. It is how early chips were made.

Last week ended with a byte on the screen and four different meanings for it. This week answers the question that immediately follows: how does voltage become a decision?

The NAND gate is the single molecule of computation. Every piece of software you have ever run — every game, every browser tab, every line of code you have written — ultimately executed as voltage flowing through gates like it.

Classic, not Evolution

There is a newer program called Logisim Evolution. Do not use it for this course. We use Logisim Classic 2.7.1 because subcircuits render with their actual gate-level visual shape, so you can look at a circuit and see its structure. Evolution draws subcircuits as featureless boxes. That difference matters a great deal by Week 13, when your CPU is built from a dozen nested subcircuits.

Create your course circuit file now

  1. Launch Logisim Classic 2.7.1.
  2. Choose File › New.
  3. Save the file immediately as CSC210_YourName.circ — using your own name, not the literal word "YourName."
  4. Keep it somewhere you will not lose it. You will open this same file every week until December.
One file. All semester. Read this carefully.

All circuits for this course must live inside a single .circ file. Every new checkpoint adds a new circuit tab to the file you just created — never a new file, and never a link to an external file.

By Week 14 this one file will contain a working CPU. Submissions that reference external Logisim files will be graded as incomplete, because the grader cannot open circuits that are not there.

Where Week 2 Fits

Phase 1 of this course — the first four weeks — builds the digital foundations everything else rests on. Each week answers a question the previous week could not:

Week 1 — Representation
How can data be stored as voltage? Binary, hex, two's complement, floating point, character encoding. Complete.
Week 2 — Mechanism (you are here)
How does voltage make a decision? Transistors, logic gates, NAND universality, Boolean algebra.
Week 3 — Computation
How do decisions become arithmetic? Adders, decoders, multiplexers, comparators.
Week 4 — Memory
How does a circuit remember? Latches and flip-flops — built, as it happens, from cross-coupled NAND gates.

The thread is: representation → mechanism → computation → memory. Week 1 gave you the vocabulary. This week gives you the machinery that operates on it.
