Week 2 is the week this course stops being reading and starts being building. Page 4 asks you to open Logisim and wire a circuit, and Assignment 2 asks you to submit five of them. Neither is possible until the software is on your machine and running.

There are three things to set up, and only the first two are needed this week:

  1. A free Saylor.org account, enrolled in CS301 — the reference textbook this course points you to all semester.
  2. Logisim Classic 2.7.1 — the circuit simulator. Needed this week.
  3. MARS 4.5 — the MIPS assembly simulator. Not needed until Week 5, but it comes in the same download, so install it now and save yourself a second round of setup in September.

Give yourself an hour, and do it early in the week. If something goes wrong — and the thing that goes wrong is almost always Java — you want to find out with days to spare, not the night Assignment 2 is due.

This page covers Windows 11

The software itself is identical on macOS, but the install has several extra steps there — Gatekeeper blocks unsigned applications, and Logisim has to be quit through File › Exit rather than the red close button or it leaves a Java process running. Mac students should follow the macOS instructions posted separately in this module instead of the steps below. The video applies to both platforms; only the click-by-click differs.

Part 1 — Saylor.org and CS301

Saylor Academy publishes CS301: Computer Architecture, a free, openly licensed course that serves as this course's reference textbook. Pages 1 through 4 of Week 2 point you at Unit 3: Fundamentals of Digital Logic Design for supplementary reading, and later weeks point at other units. That content sits behind a login, so an account you already have is one less obstacle between you and a source you may want at 10pm.

It costs nothing, there is no payment step, and enrolling takes about three minutes.

1
Go to Saylor.org and create an account

Open the CS301 course page and sign up. You can create a Saylor account with an email address and password, or sign in with an existing Google, Facebook, or LinkedIn account — any of them works.

When it asks what brings you to Saylor, Skill Development is the right answer for our purposes. You are taking one individual course, not working toward one of their degree pathways.

2
Enrol in CS301

Logged in, browse to Computer Science in the course catalog and open CS301: Computer Architecture. On the course page, click Enrol me in this course.

Saylor lists a large number of computer science courses. CS301 is the only one this course uses — do not enrol in the others expecting them to be relevant.

3
Confirm it landed

Open My Courses from the Saylor dashboard. CS301 should be listed there. Click into it and you will see the unit index — Unit 1 through Unit 9. When a page in this course says to read a specific unit, this is where you come.

Verify

You are done with Part 1 when CS301: Computer Architecture appears under My Courses and you can open Unit 3 and see reading material rather than a login prompt.

About the material itself

CS301 is genuinely useful in places and thin in others, and the last substantial revision was several years ago. That is fine for what we use it for — the fundamentals of binary, logic, and machine organization have not moved. You are not expected to read the whole thing; the SPAs will tell you which units are worth your time, and where a topic is not covered well enough, the SPA itself carries the material instead.

Part 2 — Downloading the Software

Both programs are distributed through a SharePoint link posted in this week's Canvas module, on the same page as this one. Use that link rather than searching for the software yourself: version matters here, and the copies posted for the course are the versions everything in this course was built and tested against.

Classic 2.7.1, not Evolution

There is a newer program called Logisim Evolution. Do not use it for this course. In Classic, a subcircuit keeps the visual shape you gave it, so you can look at a circuit and read its structure at a glance. Evolution draws every subcircuit as a featureless labeled rectangle. That difference is a minor annoyance in Week 2 and a serious one by Week 13, when your CPU is a dozen nested subcircuits deep. Classic is also, in the instructor's experience, the more stable of the two for this kind of work.

From the SharePoint folder, you need exactly two files for Windows:

logisim-win-2.7.1.zip Logisim Classic 2.7.1, Windows build — needed this week
mars4_5.zip MARS 4.5, the MIPS simulator — not needed until Week 5

The folder also contains a macOS build of Logisim, marked with macosx in the name. Windows users should ignore it. Selecting both Windows files and downloading them together is fine — SharePoint will bundle them into a single zip, which is why you end up extracting twice in the next step.

Put it somewhere you will find it again

Do not leave this in your Downloads folder. You will open your Logisim file every week between now and December. Make a folder you will remember — Documents\CSC210 is a reasonable choice — and work there.

If you keep it inside OneDrive, that works and gives you a backup, but let OneDrive finish syncing before you open anything. A file still showing the blue cloud icon has not been downloaded to your machine yet.

Part 3 — Extracting and First Run

This is the step that trips people up, so it is worth being precise: if you downloaded both files together, you have to extract twice. SharePoint gives you one zip that contains two more zips. Extracting once gets you the inner zips, not the programs.

1
Extract the outer zip

Right-click the downloaded file — it will be called something like OneDrive_1_8-18-2026.zip — and choose Extract All…. Windows 11 has this built in; you do not need 7-Zip or WinRAR, though either works fine if you already have one.

Point it at your CSC210 folder and click Extract.

2
Extract the two inner zips

Inside, you will find logisim-win-2.7.1.zip and mars4_5.zip. Right-click each one and Extract All… again, into the same folder.

You should end up with two folders rather than two zip files:

Documents\CSC210\ ├── logisim-win-2.7.1\ │ └── logisim-win-2.7.1.exe └── mars4_5\ └── Mars4_5.jar

If what you are looking at still has a zipper on the icon, it is still a zip — extract it.

3
Try to run Logisim

Double-click logisim-win-2.7.1.exe. Despite the .exe, this is a Java program in an executable wrapper, so it needs Java installed to start.

Windows 11 will probably show “Windows protected your PC” from SmartScreen, because the file is not code-signed and almost nobody downloads it. Click More info, then Run anyway. This is expected for Logisim and not a sign that anything is wrong.

If Logisim opens to a blank canvas with a toolbar down the left side, you have Java and you are finished with this step.

4
Try to run MARS

Double-click Mars4_5.jar. If Java is installed and registered, MARS opens: a large blue editing pane, a column of registers down the right side, and a message box along the bottom.

If instead Windows shows “How do you want to open this file?” and offers you Notepad, you do not have a working Java runtime. That is Part 4.

Verify

Part 3 is done when both programs open: Logisim to an empty circuit canvas, MARS to its editor with the register list visible. If either one does not, keep going — the cause is nearly always Java, and Part 4 fixes it.

Part 4 — Installing Java

MARS 4.5 and Logisim Classic 2.7.1 are both Java programs. They need a Java Runtime Environment (JRE) — the part of Java that runs programs. You do not need the full JDK, which is the part you would need to write Java.

Windows 11 does not ship with Java. If you have never installed it, or you reset your PC at some point, you do not have it.

1
Check whether you already have it

Open Windows Terminal or Command Prompt and type:

java -version

A version number back means Java is installed. 'java' is not recognized… means it is not, and you should continue.

2
Download the Java 8 runtime

Go to java.com's manual download page, which lists every installer rather than guessing what your browser needs. As of August 2026 this offers Java 8 Update 503.

Under Windows you will see three options:

  • Windows Online — a small stub that downloads the rest during installation.
  • Windows Offline — the complete 32-bit installer.
  • Windows Offline (64-bit) — the complete 64-bit installer. This is the one you want.

Any modern Windows 11 machine is 64-bit. The offline installer is larger but does not depend on your connection holding up mid-install, which makes it the safer choice.

3
Install it, then close your browser

Run the installer and accept the defaults. When it finishes, close your browser completely and reopen it, and close any File Explorer windows you had open. Windows does not always pick up the new file associations until then, which is why the .jar file sometimes still refuses to open right after a successful install.

If it still refuses after that, reboot. That is not a superstition here — the .jar association in particular is registered at a level that a restart reliably settles.

Verify

Run java -version again. You should get a version number back. Then double-click Mars4_5.jar and logisim-win-2.7.1.exe — both should now open.

Troubleshooting — the four things that actually go wrong
Double-clicking Mars4_5.jar opens Notepad, or asks which app to use
Java is installed but Windows is not associating .jar files with it. Fastest workaround: open a terminal in the mars4_5 folder and run java -jar Mars4_5.jar. To fix it properly, right-click the file › Open with › Choose another app › Look for another app on this PC, and point it at javaw.exe (usually under C:\Program Files\Java\jre1.8.0_xxx\bin\), then tick Always use this app.
“Windows protected your PC” when opening Logisim
SmartScreen, reacting to an unsigned executable that few people download. Click More info › Run anyway. If your antivirus quarantines it outright, restore it and add an exclusion for your CSC210 folder.
Nothing happens at all when you double-click
Almost always means you are double-clicking something still inside a zip. Windows will happily preview a zip's contents in Explorer as though it were a folder, and programs run from there fail silently. Confirm you extracted, and that the path in the address bar does not contain .zip.
You had Java before and it stopped working
A Windows reset or a Java uninstall takes the JRE with it. Reinstall from Part 4, step 2. You can safely install the 32-bit and 64-bit runtimes side by side if you are unsure which you need.

Part 5 — Create Your Course Circuit File

One last step, and it takes a minute. With Logisim open:

  1. Choose File › New.
  2. Choose File › Save As and save it immediately as CSC210_YourName.circ — your own name, not the literal word “YourName.”
  3. Save it into your CSC210 folder, alongside the two program folders.
One file. All semester. Read this carefully.

All circuits for this course must live inside a single .circ file. Every checkpoint from here to December adds a new circuit tab to the file you just created — never a new file, and never a link to an external file.

By Week 14 this one file will contain a working CPU. Submissions that reference external Logisim files are graded as incomplete, because the grader cannot open circuits that are not there.
