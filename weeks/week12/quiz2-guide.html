Worth checking before you start

  • On your CPU, ALU instructions and LD write RB. ADD RA, RB means RB ← RA + RB; LD RA, RB means RB ← RAM[RA]; ST RA, RB writes RB to RAM[RA].
  • The quarters run enable on, set on, set off, enable off, and an instruction takes 24 clicks.
  • The step is where the stepper’s 1s end: step k = Q(2k−2) AND NOT Q(2k).
  • Multi-cycle MIPS: R-type and addi 4 cycles, lw 5, sw 4, beq and j 3.
  • Wait states = (access time ÷ cycle time, rounded up) − 1.
  • syscall: service in $v0, arguments in $a0/$a1, result in $v0.
