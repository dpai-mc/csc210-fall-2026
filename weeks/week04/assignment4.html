Assignment 4: Sequential Circuits

60 points   Assesses: SLO1 — describe basic computer architecture, organization and design  |  Estimated time: ~1.25 hours

Four written questions on how feedback becomes memory, three on timing, and two circuits built in Logisim. This assignment is deliberately smaller than Assignment 3 — Quiz 1 is where this week's assessment weight sits.

Same file, two new tabs

Open the same CSC210_YourName.circ you have been building since Week 2. This week's circuits are new tabs in that file. Do not start a new file, and do not link to circuits stored elsewhere.

Every circuit must be inside this one .circ file. A submission that references circuits living in other files opens as a broken circuit on the grading machine and is marked incomplete. This is the most commonly failed requirement in the course.

Which components you may use

Anything from Logisim's Wiring folder (pins, splitters, tunnels, constants, probes) and anything from Gates (NAND, AND, OR, NOT, NOR, XOR, XNOR, buffers).

Nothing from Plexers, Arithmetic, or Memory. The Memory folder contains a D Flip-Flop, an S-R Flip-Flop and a Register that would do this assignment for you. Using any of them scores zero for that circuit, however well it works — every checkpoint from Week 5 onward instantiates the cell you built.

Active LOW — read this before you wire anything

SR_LATCH's inputs nS and nR are active LOW: drive them to 0 to act. Both at 1 is the hold state.

MEM_1BIT's inputs In and Set are active HIGH: a 1 means yes.

The polarity changes between the two circuits. If a result surprises you, check this first — it is the most common mistake in Week 4.

Part A — How Feedback Becomes Memory (20 points)

Where this is taught Q1–Q3 are answerable from Feedback: The S-R Latch, section 4.2 — particularly the paragraph tracing both stable configurations. Q4 is from Telling a Circuit When, section 4.4, where the four-gate construction is derived rather than presented.

Q1. 5 points

With nS = 1 and nR = 1, the S-R latch holds its value. Neither NAND gate contains anything that stores a bit — a NAND gate's output is simply a function of its inputs right now.

Explain what is physically holding the value. Your answer must not use the word "stored" as the explanation.

Q2. 5 points

Still with nS = 1 and nR = 1, show that both q = 0 and q = 1 are self-consistent, by tracing each gate's output in each case. Then state what that fact means about the circuit.

Q3. 5 points

Every truth table you built in Weeks 2 and 3 could be completed from the inputs alone. The S-R latch's cannot. Identify which row is the problem and explain precisely what information is missing.

Q4. 5 points

MEM_1BIT cannot reach the forbidden state. Explain why — in terms of the wiring, not in terms of a rule the user follows.

Your answer should also make clear why four gates are enough, and why a separate inverter is not needed.

Part C — Logisim Build (25 points)

Q8. Build both circuits as separate tabs in your CSC210_YourName.circ file.

Circuit 1 — SR_LATCH

Where this is taught Feedback: The S-R Latch, section 4.2. Build it there first with the Latch Bench widget if the cross-coupling is not clear from the steps below. Section 4.3 explains the flicker you will see at startup, so read it before you conclude you have miswired something.

  1. Create a new circuit tab named exactly SR_LATCH.
  2. Place two NAND gates, one above the other. Two gates is the entire circuit.
  3. Add input pins nS and nR. Set both to 2-state with pull-down behaviour.
  4. Wire nS to one input of the upper gate; wire nR to one input of the lower gate.
  5. Cross-couple them: the upper gate's output goes to the lower gate's free input, and the lower gate's output goes to the upper gate's free input.
  6. Add output pins q (from the upper gate) and nq (from the lower gate).
Verify
nSnRExpect qExpect nq
0110
1001
0011

Then the test that actually matters, which is not in the table: set the latch (nS=0), then return nS to 1 and confirm q is still 1. Reset it, release, and confirm q is still 0. That is the behaviour that makes this circuit memory, and it is the one a truth table cannot express.

Expect flickering or a red error state when the simulation first starts. With pull-down pins the latch comes up with both inputs at 0 — the forbidden state — and it settles unpredictably. That is correct behaviour for this circuit, not a wiring fault.

Circuit 2 — MEM_1BIT

Where this is taught Telling a Circuit When, section 4.4, which derives this construction one gate at a time and shows it as built in Logisim. This is the circuit the rest of the course is made of — Week 5 instantiates eight of them as a register, and every register, the program counter, the MAR, the IR and every populated byte of RAM in your finished CPU is built from this cell. It is worth the extra pass through 4.4 if anything here is unclear.

  1. Create a new circuit tab named exactly MEM_1BIT.
  2. Place four NAND gates. Two of them will be cross-coupled as the latch; two sit in front as the gating.
  3. Add input pins In and Set (2-state, pull-down) and one output pin Q.
  4. Gate A: inputs In and Set.
  5. Gate B: inputs are gate A's output and Set. There is no separate NOT gate — gate A is doing that job.
  6. Cross-couple the remaining two gates as a latch, and drive them from gate A and gate B.
  7. Bring only Q out to a pin. Do not add a Q' pin.
  8. Edit the circuit's appearance to a labelled square, with In and Set on one side and Q on the other.
Verify
  • With Set = 1, poke In back and forth. Q should follow it immediately — the cell is transparent.
  • Set Set = 0 and poke In again. Q must not move.
  • Run the three-step store: put a value on In, raise Set, drop Set. Confirm the value stays.
  • Confirm there is no combination at all of In and Set that drives both internal latch inputs low. There is no such combination — satisfy yourself that this is a property of the wiring rather than something you have to avoid.

What is and is not marked down

A five-gate MEM_1BIT with a separate NOT gate is not wrong. It behaves identically and you will get most of the marks. But the four-gate version is the one on the build page and the one Week 5 expects, so full marks go to four gates and partial to a correct five.

What does score zero is anything from Logisim's Memory folder — the built-in D Flip-Flop, S-R Flip-Flop or Register — however well the result works. The point of this assignment is that you built the cell.

Submission checklist

  • Both circuits (SR_LATCH, MEM_1BIT) are present as separate tabs
  • SR_LATCH is exactly two cross-coupled NAND gates
  • MEM_1BIT is four NAND gates — two cross-coupled, two gating, no separate inverter
  • MEM_1BIT has exactly three pins: In, Set, Q — no Q'
  • Pin names match the specification exactly, including the active-LOW n prefix on SR_LATCH
  • All input pins are set to 2-state with pull-down behaviour
  • MEM_1BIT's circuit appearance has been edited to a labelled square
  • Hold behaviour verified on both circuits: store a value, release the input, confirm the output stays
  • All circuits are contained within this single .circ file — no external file links
  • Only Wiring and Gates components are used — nothing from Plexers, Arithmetic or Memory
  • Part A and Part B answers submitted alongside the .circ file
